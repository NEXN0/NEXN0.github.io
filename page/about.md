你好，我是 NEXN0。这里是我留给自己的一个角落。

## 我在做什么

白天的工作和前端有关，晚上会花一些时间读书、写点东西，或者把白天没搞明白的问题重新想一遍。偶尔也会做些小工具，大多是自己用得上、顺手就写了的。

对这个站点的期待很简单：**把值得记下来的东西放在一个不会被弄丢的地方。**

## 关于这个站点

- 全站静态生成，没有数据库，也不需要服务端
- 内容用 Markdown 写，放在 Git 里管理
- 视觉风格参考了 [Fuwari](https://github.com/saicaca/fuwari) 这个 Astro 主题
- 部署在 GitHub Pages 上，构建和部署都由 GitHub Actions 完成
